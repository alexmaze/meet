# ADR-0035：由大模型生成可审核的短期学习计划

- 状态：Accepted
- 首次接受：2026-08-15
- 方向修订：2026-08-29
- 补充并局部修订：ADR-0033

## 背景

ADR-0033 的首个产品切片只能从代码内固定目录选取少量活动。ADR-0035 最初又把自然语言目标限制为拼音与乘法两个本地受控包。这样的路径容易校验，但无法满足家庭按实际需要配置“古诗理解”“英文购物对话”“认识太阳系”或其他具体学习内容。

本次修订把短期计划定义为配置阶段的大模型生成能力。成人填写年级、具体目标、活动数量和有效期，教学计划生成模型据此生成一份短期草稿。草稿不是正式教材，也不直接生效；家长必须看到儿童之后会听到的题目、选项、参考答案、讲解或反馈，并逐项确认后才能启用。

动态生成不等于允许成人或生成模型改写角色系统指令。模型输出必须落入通用、严格、有长度和数量上限的教学活动 DSL，再由服务端固定编译器加入儿童可拒绝、不评分、回复次数和安全恢复等不可覆盖规则。

## 决策

### 1. 产品流程

成人或管理员按现有权限选择儿童与家庭公共角色，并提供：

1. 明确的 `gradeLevel`；
2. 最多 300 字的具体 `learningGoal`；
3. 主题、互动挑战度和出现方式；
4. 3～8 个活动的 `activityCount`，默认 4 个；
5. 7 天或 14 天的 `durationDays`。

学习目标可以来自任意学科或生活学习场景，不再限定为本地拼音、乘法模板。`gradeLevel` 只控制表达参考，不代表系统判断孩子能力；不得从年龄、生日、历史、记忆、家庭资料或答题表现推断年级。

“生成短期计划”必须调用管理员已经测试、启用并绑定到 `teaching_plan_generation` 用途的文本模型。没有该绑定时，界面明确提示需要配置模型，不使用本地模板伪装成功，也不隐式复用摘要、记忆等其他用途模型。

生成只产生待确认草稿。界面展示目标摘要、年级、活动数、有效期和每项完整儿童可见内容；成人确认发布后才影响之后的新通话。编辑候选配置、生成失败或关闭预览都不能提前覆盖当前已启用内容。

### 2. 模型生成与通用活动 DSL

配置阶段模型可以生成新的题目、选项、参考答案、简短讲解、练习步骤和反馈要点，但输出只能使用 strict 候选 envelope。候选只含 `kind`、标题、目标摘要和活动列表；schema/编译器版本、学科、难度、年级、活动数和有效期由服务端从已保存的计划修订注入。候选和最终 DTO 至少满足以下边界：

- 候选根对象和活动对象拒绝额外字段，模型不得提供或覆盖服务端权威字段；
- 服务端注入权威字段后，最终对象固定 schema 与编译器版本；
- 标题、目标摘要和儿童可听文本都有独立长度上限；
- 活动数量和顺序必须与请求一致，活动 key 唯一；
- 活动类型来自有限枚举，缺省字段与类型不匹配时整份草稿失败；
- 不接受 system Prompt、角色指令、工具调用、代码、HTML、外部 URL、文件引用或要求隐藏内容的字段；
- 不能修改每次通话最多一个活动、最多两次角色回复、允许跳过、不评分、拒绝后静音和恢复基础指令等运行时规则。

服务端生成的最终 DTO 使用计划版本 `generated-teaching-plan-v2` 和编译器版本 `model-generated-teaching-content-v2`。每项活动固定为 `kind: "model_generated_activity"`、`knowledgeSource: "model_only"`，并从三种结构中选择一种：

- `explain_and_reflect`：讲解正文、反思问题、示例回答和反馈正文；
- `multiple_choice`：题目、2～4 个选项、正确选项 ID、提示和答案讲解；
- `short_answer`：题目、1～6 个可接受答案、提示和答案讲解。

单字段、单活动和整份计划分别受字符预算约束。预览必须逐项展开这些字段，不能只显示模型标题或目标摘要。

服务端先严格解析模型候选，再注入权威字段并严格解析最终 DTO，随后用固定编译器把活动内容作为有界数据嵌入教学指令。实时角色只消费已发布且仍通过结构、哈希和修订校验的编译结果，绝不把成人原始目标或模型原始响应直接当作运行时 Prompt。

模型输出合法只代表结构合规，不代表事实必然正确。服务端应独立验证数量、长度、枚举、数学等可以确定校验的约束，但不得宣称已经验证所有学科事实。成人预览与确认是当前版本不可省略的内容审核步骤。

### 3. 模型来源、联网和未来检索

当前生成请求不提供网页搜索、文件、知识库或其他工具，也不附带外部资料。因此预览必须标记“模型生成 · 未联网”，并提示“内容可能有事实错误，请家长逐项核对后启用”。不得显示虚构引用、把模型记忆表述为已查证来源，或声称所有答案必然正确。

后续如引入课程资料、知识库或联网检索，应另行决策并在协议中增加可核验来源、引用片段、检索时间与来源状态；界面必须区分“模型生成”和“基于来源生成”。在该能力落地前，短期计划始终视为未联网模型草稿。

### 4. 隐私与模型数据边界

配置阶段只向生成模型发送成人主动填写的计划字段和生成所需的固定规则，不发送：

- 儿童姓名、账号 ID、生日、学校或老师；
- 对话历史、实时转写、摘要、长期记忆或家庭资料；
- 角色完整 Prompt、媒体、录音或图片；
- Provider 凭据、内部连接信息或其他账号数据。

界面提醒成人只填写学习内容，不填写个人资料。计划表可以保存成人当前学习目标和已确认草稿；运行日志与生成请求审计只保留必要的模型配置、实际模型标识、耗时、用量、结构化错误码和哈希，不复制完整目标或模型原始响应。错误信息不得回显供应商正文、凭据或儿童数据。

### 5. 模型绑定、费用和幂等

一次生成固定解析到当时的模型配置、连接和修订。生成期间配置变化、模型调用失败、响应结构无效或编译失败时整次失败，不静默切换模型。既有已发布计划和普通聊天保持不变。

每次新生成会产生一次文本模型调用，因此可能产生模型费用。客户端以 `clientRequestId` 幂等提交，并把它绑定到儿童、角色和已保存的计划修订。网络结果未知时，同一计划修订只查询原任务；即使页面刷新后换用新的客户端请求 ID，服务端也必须返回原未知记录。已经成功落库的同修订草稿同样只返回原结果。只有成人修改并保存设置、形成新的计划修订后，才允许下一次可能计费的生成，避免因断网、刷新或重复点击产生不可见的重复费用。

生成请求固定计划修订和模型修订；发布使用内容修订与计划修订的比较并交换。候选配置变化使旧草稿失效，发布则原子切换活动指针并重置之后的新通话进度。

### 6. 实时执行与学习数据

配置生成不进入实时回复的延迟关键路径。运行时继续复用 ADR-0033 的确定性调度：每次通话最多一次邀请、儿童可选择“本次只聊天”、明确拒绝后静音、只在安全边界应用指令、等待 Provider ACK、最多两次角色回复并恢复基础指令。

活动“完成”只表示内容已呈现或结束，不表示儿童掌握。首版不依据回答自动改写后续计划，不保存错答、犹豫、发音或模型推断，不生成分数、等级、能力标签、成绩报告或跨会话 `LearningEvidence`。

## 结果

- 家庭可以为任意具体学习目标生成短期活动，不再受本地模板目录限制。
- 必须配置独立的教学计划生成模型；没有无模型回退。
- 儿童将听到的模型内容在启用前完整展示给成人，并明确标注未联网与可能出错。
- 模型只能输出严格活动 DSL，不能修改运行时安全规则或直接提供系统指令。
- 生成失败和网络未知重试不会替换既有计划，也不应造成重复模型请求。

## 验收门槛

- 拼音、乘法、语言、科学和其他具体目标都能走同一模型生成与 strict DTO 路径；
- 未配置 `teaching_plan_generation` 时明确阻止生成并提供配置指引；
- 预览展示每项题目、选项、参考答案、讲解或反馈等全部儿童可听内容，而非只显示标题；
- 预览固定显示“模型生成 · 未联网”和事实错误审核提醒；
- Prompt injection、额外字段、超长文本、URL、工具调用和试图放宽儿童安全规则的输出全部失败关闭；
- 网络未知时，同一计划修订跨 `clientRequestId` 仍返回原记录；成功落库后也不在同修订重复生成，只有保存新的设置修订才允许下一次模型调用；
- 模型失败、计划版本失效或编译失败时，既有计划与普通聊天保持不变；
- 没有儿童历史、记忆、家庭资料、转写或媒体进入配置阶段模型请求；
- ADR-0033 的拒绝、安全重置、冷却、低打扰和 Provider 精确绑定回归继续通过。

## 不包含

- 联网搜索、教材抓取、文件上传、知识库检索或引用验证；
- 对模型生成内容作“全部事实正确”或“正式课程”的保证；
- 自动判断年级、学校进度、掌握程度或升降难度；
- 发音评分、语音诊断、作业、考试、排行、打卡或家长成绩报告；
- 让配置阶段生成器读取儿童会话，或让实时规划器在成人确认后自由改写已发布内容。
