# ADR-0021：首页、角色入口与主导航

- 状态：部分由 ADR-0022 修订
- 日期：2026-08-08

## 决策

说明：第 3 项的儿童整卡通话行为已由 ADR-0022 修订为与成人相同的独立通话按钮。

1. 登录后的首页以角色卡为主，顶部优先展示最近通话和收藏角色。
2. 普通账号的角色卡提供独立通话按钮，点击卡片其他区域进入角色详情。
3. 儿童角色卡行为由 ADR-0022 修订；编辑和分享入口继续因权限隐藏。
4. 手机和平板使用角色、历史、记忆、我的底部导航。
5. 桌面使用相同信息架构并把导航转换为侧边栏。
6. 管理员功能位于我的页面内的权限路由，不开发独立后台前端。

## 理由

- 角色卡首页直接服务“找一个角色说话”的核心目标；
- 独立通话按钮兼顾快速进入和角色详情；
- 最近与收藏能减少长期使用时寻找常用角色的成本；
- 同一响应式导航比普通端和后台两套应用更易保持一致。

## 影响

- 首页 API 需要提供当前账号可见角色、最近通话和收藏数据；
- 角色卡组件需要普通与儿童两种点击策略；
- 管理路由必须同时执行前端隐藏和服务端权限校验；
- 角色详情、历史、记忆和我的页面进入第一版路由范围。
