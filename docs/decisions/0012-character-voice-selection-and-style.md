# ADR-0012：角色声音选择与风格

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. 每个角色拥有固定声音，家庭共享角色在所有账号中使用同一声音。
2. 不提供账号级音色覆盖，也不要求每次通话前重新选择声音。
3. AI 根据结构化角色卡推荐 3 个预设音色，用户试听后确认最终声音。
4. 用户仍可浏览和试听当前供应商的全部可用音色。
5. 角色卡保存语速、活力、温柔程度、情绪表现等自然语言声音风格。
6. 通话中的“慢一点”“轻声说”等要求默认只影响当前会话，不自动修改角色配置。
7. 后续克隆音色继续使用同一 Voice Profile，只替换音色类型和供应商声音 ID。

## 理由

- 固定声音是角色身份和长期熟悉感的重要组成部分；
- AI 推荐能减少试听成本，但用户试听确认可以避免角色设定与声音不匹配；
- 自然语言风格比专业音高和均衡器参数更适合普通用户，也更容易映射到不同供应商；
- 复用 Voice Profile 可以让预设音色升级为克隆音色时不修改角色、会话或记忆结构。

## 影响

- 角色创建流程需要音色推荐、试听和确认步骤；
- 供应商适配器需要提供可用音色元数据和试听能力；
- 修改共享角色声音会影响全家，需要在保存前明确提示；
- 当前会话需要保存临时声音风格覆盖，并在通话结束时丢弃；
- 供应商之间无法一一对应的声音风格由适配器降级处理。
