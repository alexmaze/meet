# ADR-0011：家庭账号创建与登录

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. 首次部署时创建第一个管理员账号。
2. 此后只有管理员可以创建家庭成员账号。
3. 不提供邀请链接、家庭邀请码或任何形式的自行注册。
4. 管理员、成人和儿童账号都使用用户名和密码登录。
5. 一台设备同时只保持一个账号的登录状态。
6. 切换家庭成员时必须退出当前账号，再输入另一个账号的用户名和密码。

## 理由

- 管理员创建账号最符合私有家庭实例的范围，不需要邮件、短信或邀请系统；
- 统一用户名密码可以减少不同账号类型的认证分支；
- 单账号设备会话实现简单，也能避免共用平板上误进入其他成员账号。

## 影响

- 系统需要首次启动管理员初始化流程和管理员成员管理页；
- 儿童账号不使用头像加 PIN 的快捷登录方式；
- 前端不实现多账号头像切换器；
- 服务端只存储密码哈希，并提供标准登录、退出和会话失效能力；
- 密码重置与恢复流程仍待确认。
