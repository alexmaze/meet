# ADR-0017：后台、断网恢复与模型故障

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. PWA 进入后台或设备锁屏时，在浏览器和系统允许的情况下尽力保持通话。
2. 如果后台期间麦克风或连接被系统暂停，用户返回前台后自动恢复。
3. 网络中断后自动重连最多约 30 秒，并保留已经确认的转写和角色上下文。
4. 重连必须幂等，不能重复显示或保存已经确认的消息。
5. 30 秒内未恢复时暂停通话，让用户选择继续重试或结束保存。
6. 模型服务出错时先重试当前模型；持续失败后暂停并等待用户选择。
7. 不在通话中静默切换模型、供应商或角色声音。

## 理由

- PWA 的后台媒体能力受浏览器和手机系统影响，尽力保持加前台恢复比承诺不可控的后台持续通话更可靠；
- 短时间自动重连可以覆盖移动网络切换和常见抖动；
- 静默切换模型可能造成声音、人设、上下文和能力突然变化，破坏角色连续性；
- 稳定事件 ID 与确认序号可以避免重连后重复对话。

## 影响

- 客户端需要监听页面可见性、媒体轨道和信令连接状态；
- 会话事件需要稳定 ID、顺序号和幂等持久化；
- 供应商适配器需要声明原会话恢复能力，并支持用已确认上下文创建替代会话；
- 通话页需要重连中、已暂停、重试和结束保存状态；
- 回归测试必须覆盖前后台切换、短暂断网、重连重复消息和供应商错误。
