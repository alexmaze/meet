# ADR-0006：会话连续性、长期记忆与录音

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. 与同一角色再次通话时，默认延续之前的关系摘要和长期记忆。
2. 用户可以发起临时对话；临时对话不生成或修改长期记忆。
3. 私人长期记忆采用分级写入：明确、可信的稳定事实可以自动保存，不确定判断进入待确认列表。
4. 用户可以查看、接受、编辑、拒绝和删除待确认记忆。
5. 原始通话音频默认不长期保存。
6. 用户可以在通话开始前开启录音，也可以在正常结束时选择保留本次临时录音。
7. 未被选择保留的临时音频在缓冲期结束后自动删除。

## 理由

- 默认延续关系可以形成陪伴感和角色连续性；
- 临时对话让用户处理一次性话题，而不污染长期关系；
- 全自动保存模型推断容易产生错误记忆，全部手工确认又会破坏使用流畅度，因此采用分级写入；
- 默认不保存音频可以控制云服务器存储量，按次保留仍能满足回听和质量分析需求。

## 影响

- 会话需要记录普通或临时模式；
- 记忆需要状态、置信度、来源会话和审阅操作；
- 会话结束流程需要执行摘要和记忆提取，临时模式跳过长期记忆写入；
- 为支持通话结束时再决定是否保留，系统需要临时缓冲双向音频并设置自动清理期限；
- 临时音频的保存格式、缓冲期限和存储位置仍待技术设计时确定。
