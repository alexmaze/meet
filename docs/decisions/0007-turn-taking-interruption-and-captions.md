# ADR-0007：轮次判断、打断与字幕

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. 实时通话默认采用免提模式，由系统自动判断用户是否说完。
2. 同时提供按住说话模式，作为嘈杂环境下的备用输入方式。
3. 自动打断使用语义判断，尽量区分真正插话、简短附和和环境噪声。
4. 通话页始终提供手动停止角色发言的按钮。
5. 普通角色默认只显示当前一句字幕，完整对话记录可以展开。
6. 数学老师等教学角色默认展开完整字幕和辅助区域。

## 理由

- 免提模式最接近自然聊天；
- 按住说话可以在电视声、儿童活动和多人交谈环境中提供可靠兜底；
- 任意声音立即打断会把自然的“嗯”等回应误判为抢话；
- 手动停止按钮可以处理语义检测失败和角色回答过长；
- 当前字幕能提供必要反馈，又不会让陪伴场景退化成文字聊天；
- 教学场景需要看到题目、公式和解释过程，适合默认显示完整辅助区。

## 影响

- 客户端和供应商适配器都需要实现免提与按住说话两种输入状态；
- 统一事件层需要表达用户语音开始、结束、有效插话和响应取消；
- 质量测试必须统计误打断、漏打断、轮次结束延迟和停止播放延迟；
- 字幕组件需要当前句、完整记录和教学辅助三种显示层级。
