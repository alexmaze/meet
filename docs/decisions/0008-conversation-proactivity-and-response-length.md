# ADR-0008：角色主动程度与回复长度

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. 接通后由谁先说按角色配置，默认由角色结合当前关系自然打招呼。
2. 用户沉默约 10–15 秒后，角色可以自然追问或关心一次。
3. 如果用户仍无回应，角色保持安静，不连续主动找话题。
4. 回复长度按角色和语境动态调整：陪伴角色默认简短自然，教学角色适合分步骤解释。
5. 用户可以在通话中通过“简单点”“详细点”“慢一点”等自然语言临时调整表达方式。

## 理由

- 主动开场能减少接通后的僵硬等待，同时允许少数角色选择等待用户先说；
- 一次沉默追问能表达在场感，反复追问则容易打扰用户思考或离开；
- 固定长度无法同时满足自然陪伴和教学讲解；
- 用自然语言即时调整比进入设置页更符合实时聊天习惯。

## 影响

- 角色配置需要独立的开场、沉默追问和回复风格字段；
- 客户端或服务端需要管理空闲计时器，并确保每次连续沉默最多触发一次追问；
- 运行时提示词需要结合角色策略与当前会话中的临时偏好；
- 质量测试需要关注角色长篇独白和沉默时过度主动的问题。
