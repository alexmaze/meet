# ADR-0003：家庭账号与通话界面

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. 手机和平板是第一版的主要终端，桌面浏览器保持兼容。
2. 一个私有部署实例支持多个家庭成员账号，每个成员独立登录。
3. 每个账号的个人资料、对话历史和角色长期记忆相互隔离。
4. 项目不开放公众注册，也不建设面向多个家庭的多租户平台。
5. 通话界面采用自适应形态：默认是以角色为中心的沉浸式通话，数学老师等角色可以展开字幕、题目和辅助内容。

## 理由

- 实时语音聊天更适合随手可用的手机和平板；
- 儿童与成人使用同一个家庭实例时，需要避免身份、历史和记忆混淆；
- 独立登录比每次手工选择对话身份更可靠；
- 陪伴角色需要弱化文字和设置，教学角色则需要展示题目与过程，因此单一固定布局无法兼顾两者。

## 影响

- 登录、账号管理和数据隔离进入 MVP 范围；
- 会话、消息、记忆和用量记录都必须关联家庭账号；
- 需要创建首个管理员账号，并设计家庭成员的创建与密码恢复流程；
- 需要继续确认角色共享方式、管理员权限以及是否存在儿童账号类型；
- 前端应采用同一通话框架加可配置辅助区域，而不是维护完全独立的两套聊天页面。
