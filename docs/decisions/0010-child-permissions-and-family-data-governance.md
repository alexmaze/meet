# ADR-0010：儿童权限与家庭数据管理

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. 每个儿童账号分别配置管理员是否可以查看其对话历史、长期记忆和已保留录音，默认允许。
2. 成人账号的私人对话、长期记忆和录音始终只对本人可见，管理员不能读取。
3. 儿童只能使用家庭公共角色，不能创建、编辑或共享角色。
4. 成人可以创建私人角色，并主动共享给全家；管理员创建的角色默认全家共享。
5. 只有管理员可以创建、编辑或删除家庭资料。
6. 成人和儿童可以在角色对话中读取使用家庭资料，但不能修改。

## 理由

- 按儿童账号配置兼顾不同年龄和家庭使用方式；
- 成人独立账号需要保持真正的私人空间；
- 儿童角色权限保持简单，角色内容统一由管理员或成人准备；
- 家庭资料会影响所有成员的角色对话，因此只允许管理员维护。

## 影响

- 儿童账号需要单独的管理员历史访问设置，所有历史和记忆查询都必须执行该权限判断；
- 管理员不能因为拥有系统管理权限而绕过成人数据隔离；
- 服务端必须拒绝儿童账号的角色创建、编辑和共享请求，而不能只隐藏前端入口；
- 家庭资料写接口只允许管理员访问，成人和儿童只有读取权；
- 仍需确定家庭账号的创建、登录、设备保持和密码恢复体验。
