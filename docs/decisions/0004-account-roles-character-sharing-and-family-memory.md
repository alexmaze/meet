# ADR-0004：账号角色、角色共享与家庭资料

- 状态：部分由 ADR-0010 修订
- 日期：2026-08-08

## 决策

说明：以下第 2 项中的“儿童使用更简单界面”已由 ADR-0022 修订；第 4 项中儿童创建角色的部分及家庭资料编辑权限已由 ADR-0010 修订。其余决策继续有效。

1. 家庭账号分为管理员、成人和儿童三种类型。
2. 儿童账号不能修改模型供应商、API 凭据等系统设置；界面是否简化由 ADR-0022 修订。
3. 内置预置角色和管理员创建的角色对全家共享。
4. 成人创建的角色默认私有，创建者可以主动共享给全家；儿童角色权限由 ADR-0010 修订。
5. 共享角色只共享角色设定和声音配置，不共享成员与角色之间的对话、摘要或长期记忆。
6. 每个账号的私人记忆保持隔离，同时提供一份显式维护的家庭资料，用于共享称呼、关系和共同信息。
7. 私人对话不会在未明确同意的情况下自动进入家庭资料。

## 理由

- 不同账号类型可以同时满足家庭管理、成人使用和儿童权限控制；
- 公共角色库避免每个家庭成员重复创建常用角色；
- 私人角色默认不打扰其他成员，同时保留主动分享的便利；
- 把家庭事实与私人角色记忆分开，可以让角色理解基本家庭关系，又不会让私人谈心内容串号。

## 影响

- 用户、角色、会话和记忆都需要明确的所有者与可见性字段；
- 服务端必须在每次读写时依据登录账号校验数据范围；
- 共享角色修改后会影响全家，需要在编辑体验中明确提示；
- 家庭资料需要独立的数据模型、编辑页和变更记录；
- 管理员查看儿童历史、儿童角色权限和家庭资料编辑权限已由 ADR-0010 确定。
