# ADR-0014：预置角色、密码恢复与备份边界

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. 首次部署后直接提供儿童英雄、数学老师和成人情绪陪伴三个可通话的家庭共享角色。
2. 管理员可以复制和修改预置角色，并可以恢复当前应用版本提供的原始角色配置。
3. 恢复预置角色配置不能删除家庭成员与该角色的对话或记忆。
4. 管理员可以重置家庭成员密码；重置时撤销该成员现有登录会话。
5. 管理员忘记密码时通过服务器管理命令重置，不接入邮箱找回。
6. 应用不实现数据库和媒体的完整备份或恢复功能。
7. 完整数据备份依赖云服务器磁盘快照；角色卡导出不属于完整备份。

## 理由

- 开箱可通话的预置角色能直接展示产品价值，复制和恢复同时保留定制空间；
- 私有家庭实例使用管理员重置和服务器命令即可完成密码恢复，不需要外部邮件服务；
- 云服务器磁盘快照已经能够覆盖数据库、媒体和运行配置，第一版没有必要重复开发备份系统。

## 影响

- 预置角色需要稳定系统标识、来源版本和恢复逻辑；
- 密码重置只设置新密码哈希，不能查看原密码，并需要撤销旧会话；
- 应用内的成人隐私是正常授权边界，不以密码学方式对抗拥有服务器控制权的管理员；
- 部署文档必须明确配置磁盘快照，并说明恢复步骤；
- 未配置云快照会造成单点数据丢失风险，应用不会提供额外兜底。
