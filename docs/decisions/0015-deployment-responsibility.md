# ADR-0015：部署责任边界

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. 项目所有者自行选择并管理国内云服务器。
2. 云平台、服务器规格、域名、HTTPS 证书、磁盘快照和生产运维不纳入 Meet 应用产品范围。
3. 应用不替项目所有者选择、购买或管理生产云资源。
4. 应用保持通过配置运行和部署的能力，不与某个云厂商的托管部署服务绑定。

## 影响

- 后续需求讨论不再询问具体云平台、域名或快照计划；
- 架构仍以中国大陆网络环境和 HTTPS 浏览器访问为前提；
- 只有项目所有者后续明确提出部署请求时，才补充相应部署脚本或执行生产部署；
- 模型供应商接入和应用运行配置仍属于项目本身，生产基础设施运维不属于。
