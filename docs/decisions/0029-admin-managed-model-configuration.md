# ADR-0029：管理员维护模型连接、模型与用途绑定

- 状态：Accepted
- 日期：2026-08-13
- 修订：ADR-0023、ADR-0024、ADR-0025、ADR-0028 中固定环境变量、模型允许列表和隐式默认模型的配置方式

## 背景

现有千问、豆包实时链路和后台文本分析都从进程启动环境读取固定凭据与模型。家庭管理员无法在产品内维护多个连接、测试候选配置或分别选择摘要与记忆模型；改变配置也需要重启进程。角色已经通过 Provider Profile 与 Voice Profile 保存引用，因此可以在保留角色数据的前提下，把配置控制面迁入数据库。

## 决策

1. “我的”页面提供管理员专属模型设置，分为实时语音和文本模型。连接按协议适配器划分，一个连接可以承载多个同类模型；新增协议仍需实现适配器。
2. 实时首期使用千问和豆包适配器，文本首期只支持 Bearer API Key、HTTPS Base URL、标准 `/chat/completions`、JSON Mode，以及受控的标准/阿里百炼兼容预设。
3. API 密钥以明文保存在服务端 PostgreSQL。API 只返回 `hasCredential`，不得回显密钥；密钥不得进入日志、审计详情、错误响应或版本库。数据库或快照泄露会直接暴露密钥，部署者必须按这一风险保护数据库与快照。
4. 连接修改写入候选修订。候选配置通过关联模型的真实测试后，端点、凭据和兼容预设在同一事务中切为活动修订；测试失败不影响旧活动修订。
5. 模型和音色采用草稿、已启用、已停用状态。模型必须测试成功后才能启用；自定义音色必须随实时模型完成短试听测试后才能选择。被角色、用途或工作项引用，或曾经启用过的模型不能删除。
6. 用途绑定包括 `realtime_default`、`conversation_summary` 和 `memory_extraction`。新角色预选实时默认，已有角色不随默认变化；摘要与记忆可以绑定不同文本模型。
7. 管理员和成人可以为自己有编辑权的角色选择已启用实时模型与音色；儿童没有选模或模型管理入口。模型停用不迁移角色或用途，不触发静默回退。
8. 新通话、试听和握手每次从数据库解析角色的模型、连接和音色。活跃通话继续使用建连时解析出的配置；停用后新请求明确失败。
9. 会话完成时为摘要和记忆分别创建持久工作项。有有效用途绑定时固定写入模型配置 ID 后入队；没有绑定时进入等待配置，不影响会话保存。补齐绑定后自动补发等待项。已入队工作即使模型后来停用，也继续使用原模型配置；结果记录配置 ID 与实际模型 ID。
10. 升级迁移保留已有 Provider Profile、Voice Profile 和角色引用，但将其置为未配置草稿。管理员创建相同供应商和模型 ID 的配置时重新挂接原 Profile，再测试、启用；不读取或导入遗留模型环境变量。
11. 管理操作记录不含密钥的审计事件，并使用修订号进行并发控制。管理页只展示等待和失败工作数量，不建设队列管理面板。

## 后果

- 首次升级后，账号、角色、历史和记忆仍可使用；完成模型配置前，通话、试听和后台分析显示明确的缺失配置状态。
- Qwen Plus/Flash 与豆包模型 ID 不再由共享协议枚举封死，但仍必须匹配对应适配器、测试成功且已启用。
- `.env` 继续保存数据库、认证和媒体等基础配置，不再承载模型供应商凭据与模型默认值。
- 自动测试只使用模拟上游；只有管理员主动点击测试才会调用可能计费的真实模型接口。

## 不包含

- 任意自定义请求头、任意供应商 JSON 参数或明文 HTTP 本地模型；
- 新实时协议的无代码接入；
- 自动故障切换供应商、模型或音色；
- 密钥加密托管或外部 Secret Manager 集成；
- 队列 Dashboard。

## 重新评估条件

- 需要接入非 Bearer 或非 Chat Completions 文本供应商；
- 私有部署的威胁模型要求数据库内凭据加密；
- 工作项规模需要独立队列运维界面；
- 供应商协议允许在不中断会话的情况下安全切换模型或声音。
