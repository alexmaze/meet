# ADR-0005：角色创建与第一版视觉范围

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. 角色创建同时提供 AI 快速创建和手工高级编辑。
2. 用户可以用自然语言描述目标角色，由 AI 生成一份可查看、可修改的角色卡草稿。
3. 角色卡采用结构化字段，包括背景、性格、与用户的关系、语言习惯、情绪风格、对话目标和示例台词。
4. 第一版不支持上传剧本、文档或知识库作为角色资料。
5. 第一版使用静态头像，并通过呼吸、聆听、思考和说话等轻量动画表达实时状态。
6. 第一版不实现 Live2D、数字人或口型同步。

## 理由

- AI 快速创建降低新建角色门槛，高级编辑保证用户仍然能精确控制人设；
- 结构化角色卡比单段自由提示词更容易修改、复用、迁移和排查人设问题；
- 示例台词能以较低实现成本增强语气和角色感；
- 轻量状态动画已经可以表达实时互动状态，不会分散实时语音技术验证的投入。

## 影响

- 需要一个返回结构化数据的角色生成接口，以及对应的数据校验；
- 需要普通编辑和高级编辑两层角色表单；
- 运行时提示词由结构化角色卡编译生成；
- 客户端动画由供应商无关的实时事件驱动；
- 文档知识库、Live2D 和口型同步进入后续版本候选。
