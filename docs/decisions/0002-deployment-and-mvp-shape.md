# ADR-0002：部署地区与第一版产品形态

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. 应用主要在中国大陆使用。
2. 私有应用服务部署在国内云服务器。
3. 第一版采用通用角色平台，而不是只实现儿童陪伴、教学或成人陪伴中的一个场景。
4. 第一版至少预置三类角色：儿童英雄、数学老师、成人情绪陪伴。

## 理由

- 国内部署能让浏览器访问私有服务的网络路径更稳定；
- 使用地区进一步支持把千问和豆包作为首要实时模型候选；
- 三种预置角色可以验证同一套实时会话、人物提示词和记忆系统是否具备足够通用性；
- 通用平台保留创建更多自定义角色的空间。

## 影响

- 应用需要通过域名和 HTTPS 提供浏览器访问，以稳定使用麦克风能力；
- 暂不建设公开注册、多租户计费或角色市场；
- 数据模型仍需考虑一个私有实例内是否存在多个家庭成员身份；
- 三类角色需要分别设计提示词、开场方式和验收脚本，不能只更换名称和头像；
- 云端模型和其他依赖应优先验证中国大陆网络可用性。
