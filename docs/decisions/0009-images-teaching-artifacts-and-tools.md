# ADR-0009：图片、教学辅助内容与工具调用

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. 第一版支持在通话中上传图片或调用手机相机拍照。
2. 第一版不支持持续实时摄像头或视频理解。
3. 数学老师辅助区支持题目图片、Markdown、LaTeX 公式、分步讲解卡片和最终结论。
4. 角色更新教学辅助内容时，语音通话保持进行，用户仍可随时插话。
5. 第一版不实现可自由绘制的互动白板。
6. 第一版只实现服务端计算器工具。
7. 工具框架按角色配置允许列表并保留扩展接口，但第一版不加入联网搜索、天气或通用外部操作。

## 理由

- 拍摄题目是手机和平板上最自然的教学输入方式；
- 持续视频会显著增加带宽、模型限制和界面复杂度，对第一版核心价值帮助有限；
- 公式和分步卡片能解决纯语音难以表达复杂数学内容的问题；
- 计算器可以降低精确计算错误，同时用较小范围验证实时模型的工具调用链路；
- 限制工具数量可以把第一版精力继续放在自然语音和角色体验上。

## 影响

- 实时供应商适配器需要声明图片输入能力，并为不支持的供应商准备独立视觉分析回退路径；
- 会话消息模型需要支持图片附件；
- 前端需要 Markdown、LaTeX 和结构化教学卡片渲染能力；
- 服务端需要统一工具注册、参数校验、执行结果回传和错误事件；
- 图片保存期限和历史记录中的显示方式仍待确定。
