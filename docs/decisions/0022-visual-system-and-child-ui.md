# ADR-0022：视觉系统、通话构图与儿童界面

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. 产品使用简洁、中性的基础设计系统，每个角色可以应用自己的主题色、背景和氛围。
2. 不把整个应用固定为科幻霓虹、卡通或单一电影风格。
3. 通话页以大幅静态角色立绘为中心，背景由角色图像模糊延展。
4. 当前一句字幕悬浮显示，通话控制固定在底部，完整字幕和教学辅助区按既定规则展开。
5. 儿童与成人使用相同的视觉组件、布局、控件尺寸和角色卡交互。
6. 儿童与成人的差异只来自账号权限；儿童看不到创建角色、编辑、分享和系统设置等无权操作。
7. 所有账号的角色卡都使用独立通话按钮，点击其他区域进入角色详情。

## 理由

- 中性基础与角色主题能够同时容纳英雄、老师和情绪陪伴等差异很大的角色；
- 大幅角色画面强化通话沉浸感，同时保留字幕与操作可读性；
- 成人和儿童共用界面可以避免两套交互逐渐分叉，权限控制已经足以限制儿童操作。

## 影响

- 角色数据需要有限的主题配置和背景资产引用；
- 设计系统需要保证角色主题不会破坏对比度与核心控件辨识度；
- 删除儿童整卡通话和特殊尺寸分支，角色卡组件只依据权限显示操作；
- ADR-0004 的儿童简化界面描述与 ADR-0021 的儿童整卡通话决定被本决策覆盖。
