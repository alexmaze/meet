# ADR-0016：并发、PWA 与通知范围

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. 应用不设置全局并发通话数量上限。
2. 实际并发容量由部署资源、网络条件和模型供应商配额决定。
3. 外部资源不足时只向受影响的会话返回明确错误，不通过中断其他成员会话释放容量。
4. 第一版支持安装为 PWA，并以独立全屏窗口运行。
5. PWA 可以缓存应用外壳，但所有 AI 实时聊天仍需联网。
6. 第一版不实现推送通知、定时提醒或角色主动来电。

## 理由

- 私有部署的资源条件由项目所有者决定，应用没有必要人为设置固定并发上限；
- PWA 已能满足手机和平板的桌面入口和全屏体验，不需要原生应用；
- 推送和主动来电不影响第一版自然角色聊天的核心验证。

## 影响

- 实时会话必须彼此隔离，并正确传播供应商配额和服务器资源错误；
- 监控需要显示当前活跃会话和资源错误，但不提供应用级硬上限设置；
- 前端需要 PWA Manifest、图标、启动配置和最小 Service Worker；
- 第一版不开发通知权限申请、推送服务或后台调度系统。
